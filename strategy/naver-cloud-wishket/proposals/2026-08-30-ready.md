## Priority 1 — Python/Node.js 기반 건설 AI 검색 플랫폼 백엔드 개발

- 프로젝트: https://www.wishket.com/project/157915/
- 상태: 모집 중
- 마감: 2026-09-08
- 예산: 협의 후 결정
- 기간: 120일
- 위치: 서울 강동구 강동역 인근
- 적합도: 90/100
- NCP 매핑: CLOVA OCR → Object Storage → Vector/RAG → CLOVA Studio → API Gateway/Cloud Functions

### 지원 메시지
안녕하세요. 사내 건설 문서 및 도면 검색을 위한 AI 챗봇 2차 고도화 프로젝트로 이해했습니다. 신규 구축보다는 현재 검색·챗봇 구조의 정확도와 운영 안정성을 개선하는 것이 핵심이라고 보고 있습니다.

저는 Python 기반 데이터 처리·API 연동과 AI 업무자동화 구조를 중심으로, 문서 수집/정규화 → 메타데이터 및 OCR → 임베딩/검색 → RAG 답변 → 근거문서 표시 → 사용 로그/평가까지 하나의 백엔드 파이프라인으로 정리해 접근하겠습니다. 기존 Node.js 또는 현재 클라우드 환경을 유지하면서 필요한 구간만 단계적으로 개선하는 방식이 적합합니다.

국내 클라우드 요구가 있는 경우 CLOVA OCR과 CLOVA Studio를 적용할 수 있으며, 특정 모델을 전제로 하기보다 검색 정확도, 근거문서 회수율, 응답시간, hallucination 비율을 KPI로 비교해 최종 구조를 결정하겠습니다.

초기 합류 시 1주차에 현재 데이터 흐름과 검색 품질을 진단하고, 2주차부터 병목이 큰 구간부터 개선안을 적용할 수 있습니다.

### 첫 미팅 질문
1. 현재 문서/도면 저장소와 파일 포맷은 무엇인지
2. 기존 Vector DB·검색엔진·LLM 구조는 무엇인지
3. 현재 가장 큰 문제는 검색 recall, 답변 정확도, 속도, 권한 중 무엇인지
4. 정답셋 또는 검색 품질 평가셋이 존재하는지
5. 문서 권한과 사내 보안등급을 어떻게 처리하는지

### 제안 포지셔닝
- 전체 재구축보다 2차 고도화에 집중
- 검색/RAG 품질 KPI를 먼저 제시
- NCP는 선택형 국내 클라우드 옵션

## Priority 2 — GCP/AWS 기반 AI 비정형 주문 처리 시스템 아키텍처 설계

- 프로젝트: https://www.wishket.com/project/157579/
- 상태: 모집 중
- 마감: 2026-09-08
- 예산: 4,000,000원/월
- 기간: 50일
- 근무: 주 4일 재택
- 적합도: 90/100
- NCP 매핑: CLOVA OCR / CLOVA Studio를 비교 옵션으로 제안, 기존 GCP/AWS 우선 존중

### 지원 메시지
안녕하세요. Multimodal AI로 비정형 주문 데이터를 구조화하는 핵심 로직은 이미 개발되어 있고, 현재 과제는 이를 실제 운영 가능한 클라우드 아키텍처와 대시보드·자율형 챗봇으로 안정화하는 단계로 이해했습니다.

이 프로젝트에서는 클라우드 교체보다 운영 구조가 중요하다고 봅니다. 기존 GCP/AWS 환경을 우선 유지하면서 입력 데이터 → AI 구조화 → 검증 → DB 저장 → 사용자 대시보드 → Agent 액션을 명확히 분리하고, 실패 재처리·감사로그·비용 모니터링까지 포함해 운영 가능한 형태로 정리하겠습니다.

비정형 주문의 이미지/PDF/텍스트 비중이 높다면 CLOVA OCR 또는 CLOVA Studio를 보조 옵션으로 비교할 수 있지만, 기존 자산을 무리하게 NCP로 이전하기보다 정확도와 API 비용을 기준으로 선택하겠습니다.

50일 일정에서는 1) 현행 아키텍처 분석, 2) 운영 아키텍처 확정, 3) 핵심 API/대시보드 연동, 4) 부하·오류·비용 테스트 순으로 범위를 고정하는 것이 현실적입니다.

### 첫 미팅 질문
1. 비정형 주문의 주요 입력 채널과 포맷
2. 현재 Multimodal 모델과 정확도
3. 사람이 반드시 검수해야 하는 필드
4. SQL Server/NoSQL 데이터 모델과 트랜잭션 요구사항
5. 10월 론칭 예상 트래픽과 SLA

### 제안 포지셔닝
- 기존 GCP/AWS 존중
- AI 모델보다 운영 아키텍처·오류복구 강조
- OCR/NCP는 성능 비교 옵션으로만 제시

## Priority 3 — AI Agent/LLM 기반 B2C·B2B 서비스 기획 및 PM

- 프로젝트: https://www.wishket.com/project/157614/
- 상태: 모집 중
- 마감: 2026-09-02
- 예산: 5,500,000원/월
- 기간: 90일
- 위치: 서울 영등포구 여의도
- 적합도: 91/100
- NCP 매핑: CLOVA Studio + Agentic workflow + API Gateway, 엔터프라이즈 AI 상품화

### 지원 메시지
안녕하세요. B2C·B2B AI 서비스의 기획부터 AI Agent 엔드투엔드 워크플로우, 고객사 요구사항 반영, 출시까지 총괄하는 역할로 이해했습니다.

저는 기술 구현 자체보다 고객의 업무 문제를 KPI와 시스템 요구사항으로 변환하는 방식으로 접근합니다. 초기에는 고객군별 핵심 업무를 분류하고 PRD·Agent workflow·데이터/API 요구사항·검수 기준을 하나의 문서 체계로 정리한 뒤, 개발팀이 바로 구현 가능한 backlog와 WBS로 전환하겠습니다.

Enterprise AI에서는 모델 성능만큼 권한, 비용, 로그, human-in-the-loop, 실패 처리, 고객사별 커스터마이징 범위가 중요합니다. 이 부분을 제품 요구사항 단계에서 먼저 정의해 PoC가 단발성 데모로 끝나지 않고 B2B 솔루션으로 반복 판매될 수 있는 구조를 만드는 데 집중하겠습니다.

NCP 적용 시 CLOVA Studio를 한국어·국내 클라우드 고객용 모델 옵션으로 포함하고, 타 모델과도 교체 가능한 구조를 전제로 설계하겠습니다.

### 첫 미팅 질문
1. 현재 B2C/B2B 각각의 대표 use case와 고객군
2. Agent가 수행해야 할 핵심 action과 승인 구조
3. 기존 개발팀 구성과 PM의 의사결정 범위
4. 출시 KPI와 고객사별 커스터마이징 허용 범위
5. 3개월 종료 시 반드시 완성되어야 하는 산출물

### 제안 포지셔닝
- 기술 PM + 사업화 관점
- PRD → workflow → backlog → KPI 일관성 강조
- 국내 Enterprise AI/NCP 옵션을 상품화 관점에서 제시
