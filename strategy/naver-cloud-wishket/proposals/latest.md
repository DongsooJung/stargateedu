# Wishket × NAVER Cloud TOP 3 제안서 초안

자동화가 아직 한 번도 실데이터로 실행되지 않았습니다.

GitHub 저장소의 Actions secrets에 아래 두 값을 등록한 뒤 `Update Wishket NCP Radar` 워크플로를 수동 실행하거나 다음 일일 스케줄을 기다리면 이 파일이 자동 갱신됩니다.

- `NAVER_SEARCH_CLIENT_ID`
- `NAVER_SEARCH_CLIENT_SECRET`

생성된 제안서는 공개 검색 스니펫 기반의 초안이므로 실제 제출 전 Wishket 로그인 화면에서 모집 상태, 상세 요구사항, 예산, 계약형태를 반드시 재확인합니다.
