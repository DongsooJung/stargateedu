## 1. AI 기반 문서 검색·분석 서비스 파일럿 개발 AI Engineer

- 프로젝트: https://www.wishket.com/project/157739/
- 적합도: **95/100**
- 권장 구조: **AI Quick PoC → Business Automation Build**
- NCP 매핑: CLOVA Studio + CLOVA OCR + API Gateway/Cloud Functions

### 지원 메시지 초안
안녕하세요. 이번 프로젝트는 문서 검색·분석 정확도와 실제 업무 활용성을 빠르게 검증하는 파일럿으로 이해했습니다. STARGATE는 문서 수집·정규화, 권한별 검색, RAG 답변, 근거 문서 표시, 사용 로그까지 하나의 PoC 범위로 구성할 수 있습니다.

초기 2주에는 대표 문서셋과 핵심 질문군을 정해 정확도·응답시간·업무시간 절감 KPI를 측정하고, 성과가 확인되면 운영형 관리자 기능과 사내 시스템 연동으로 확장하는 방식을 제안합니다. 국내 클라우드가 적합한 경우 CLOVA Studio와 CLOVA OCR을 조합하되, 실제 성능과 비용을 기준으로 최종 구조를 결정하겠습니다.

### 첫 미팅 확인사항
- 문서 종류·수량·보안등급
- 정답셋 또는 검증 담당자 존재 여부
- 사용자별 권한 분리 필요 여부
- 파일럿 성공 기준과 본구축 전환 기준

## 2. Python/LLM 기반 특허 자동화 B2B SaaS AI 엔지니어 개발

- 프로젝트: https://www.wishket.com/project/157881/
- 적합도: **93/100**
- 예산 신호: **500만원/월**
- 권장 구조: **Business Automation Build**
- NCP 매핑: CLOVA Studio + API Gateway/Cloud Functions

### 지원 메시지 초안
안녕하세요. 특허 업무의 반복 검색·분석·초안 생성 과정을 B2B SaaS 워크플로우로 자동화하는 프로젝트로 이해했습니다. Python 기반 API 계층과 LLM/RAG 계층을 분리하고, 검색 근거와 결과 이력을 남기는 구조로 설계하겠습니다.

초기에는 가장 반복성이 높은 1~2개 업무 흐름을 고정해 정확도와 처리시간을 검증하고, 이후 고객사별 데이터·권한·요금제 구조를 확장하는 방식이 적합합니다. 네이버클라우드 적용 시 CLOVA Studio를 모델 계층으로 검토하고 API Gateway/Cloud Functions를 연동 계층에 활용할 수 있습니다.

### 첫 미팅 확인사항
- 특허 데이터 원천과 API/라이선스 범위
- 자동화 대상 업무의 현재 처리시간
- 결과물 검수 책임과 오류 허용범위
- 고객사별 테넌트·권한·과금 구조

## 3. Python/GCP 기반 마케팅 자동화 플랫폼 AI Agent 개발

- 프로젝트: https://www.wishket.com/project/157775/
- 적합도: **91/100**
- 예산: **750만원/월**
- 모집 마감: **2026-09-01**
- 권장 구조: **Business Automation Build**
- NCP 매핑: CLOVA Studio + API Gateway/Cloud Functions

### 지원 메시지 초안
안녕하세요. 2차 오픈 이후 운영 중인 마케팅 자동화 플랫폼에 AI Agent를 추가하고 기존 시스템과 안정적으로 연동하는 프로젝트로 이해했습니다. 기존 GCP 구조를 존중하면서 Agent 기능을 독립 서비스로 분리하고, API 계약·로그·실패 복구·비용 모니터링을 명확히 관리하는 방식으로 접근하겠습니다.

Python 기반 Agent 개발과 업무 API 연동을 우선하며, NCP 전환 자체를 전제로 하지 않습니다. 다만 한국어 생성·분석 기능 또는 국내 클라우드 요구가 생길 경우 CLOVA Studio를 선택지로 비교해 성능·비용 기준으로 제안하겠습니다.

### 첫 미팅 확인사항
- 현재 GCP 아키텍처와 Agent 연동 지점
- 기존 마케팅 데이터/API 범위
- Agent가 실행 가능한 액션과 승인 절차
- 운영 SLA·비용 상한·로그 요구사항
