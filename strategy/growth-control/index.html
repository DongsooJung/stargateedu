6. 데이터 연결 상태

필요 연결

GA4 Data API는 사용자·세션·전환을, Google Search Console API는 페이지별 클릭·노출·CTR·평균순위를 공급한다. 네이버는 Search Advisor 데이터를 보조 지표로 사용한다.

보안 구조

API 인증키나 서비스 계정 비밀값은 GitHub Pages 프론트엔드에 넣지 않는다. GitHub Actions 또는 서버리스 함수가 인증 후 집계 결과만 data.json에 갱신하는 구조가 적합하다.
