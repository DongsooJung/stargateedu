구현된 API

GET /v1/statusCloud Run 및 각 서비스의 구성 여부. secret 값은 반환하지 않음.
POST /v1/ai/analyzeGemini 기반 연구자료 분석. 기본 temperature 0.2.
POST /v1/places/searchPlaces API (New) Text Search. 한국어/한국 지역 기본값.
POST /v1/data/view운영자가 allowlist에 지정한 BigQuery 공개 View만 조회.
비용 통제: Places는 필요한 필드만 요청하고, BigQuery는 공개 View allowlist + 요청별 최대 처리 바이트를 사용합니다. Gemini 모델은 환경변수로 교체할 수 있습니다.
