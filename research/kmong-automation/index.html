안전장치

승인 없는 자동 요청이 발생하지 않도록 실패 폐쇄 방식으로 구현했습니다.

  • 허가 환경변수 3종이 없으면 네트워크 실행 차단
  • robots.txt 확인 실패 또는 비허용 URL은 즉시 중단
  • 요청 간격 기본 6초, 2초 미만 설정 거부
  • 401·403·429 응답 시 즉시 전체 수집 중단
  • 연락처·프로필 원문·리뷰 본문·상세 설명은 저장 제외
  • 로컬 CSV는 서버 전송 없이 현재 브라우저에서만 처리
